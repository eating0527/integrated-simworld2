# 01 — 響應式 Workspace 抽屜

**What to build:** 讓筆電使用者在 CSS viewport 為 1200px 時維持雙側欄、1199px 起使用可完整操作的抽屜，保留 3D 主場景與可存取的控制。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 1200px 維持雙側欄；1199px 起左右欄改為抽屜，且不造成水平捲軸。
- [ ] 進入抽屜斷點時左右欄皆預設收合；固定操作可開啟「控制」或「歷史」，且同時僅能開啟一側。
- [ ] 抽屜模式的控制欄寬為 320px、歷史欄寬為 360px；窄螢幕皆以 `calc(100vw - 44px)` 為上限，桌面側欄寬度規則不變。
- [ ] 抽屜頂端提供對應欄位的可見關閉按鈕，並保留遮罩點擊、Escape、焦點圈限與關閉後回到原觸發按鈕。
- [ ] 抽屜本體是唯一主要垂直捲動區，關閉列固定於頂端；僅既有表格或長清單可保留必要的內部捲動。
- [ ] 1280×800 維持雙側欄；1164×727 使用抽屜，兩者都可完整操作。
