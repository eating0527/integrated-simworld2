設計一修訂：Bind 控制模式

Bind 預設關閉，讓 UAV GPS 與 USRP 可獨立測試；開啟後才組成同一個聯合任務。

Bind OFF（預設）
UAV GPS：獨立 Start / Stop
↓
gps mission_id → gps.csv
USRP：Test / USRP + Start / Stop
↓
noise mission_id → noise.csv

不要求另一台裝置連線；適合各自測試與除錯。

Bind ON
開始前檢查 GPS + RasPi 都 ready
↓
一個共同 mission_id
GPS Start
USRP Start
↓ 分開監控與留檔
gps.csv + noise.csv 配對

單路失敗不停止另一條；整體顯示 partial_failed。

前端控制規則

  • Bind 開關不應在任一服務執行期間變更。
  • Bind OFF：兩個狀態區各有獨立 Start / Stop。
  • Bind ON：顯示共同 Start；Stop 建議仍可選「全部停止」或個別停止。
  • Test／USRP 模式只影響 RasPi service，不影響 GPS。

任務資料

bind: false → 各自 mission_id
bind: true → shared mission_id + gps/noise 子任務狀態
